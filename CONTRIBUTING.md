# Contributing

Thanks for looking. Jarvis's source code is **private**: it runs a real household, so there are no pull requests to the code and no code to clone.

What you can do here:

- **Ask** how something works or why: [open a question](https://github.com/Tardisyuan/jarvis-showcase/issues/new/choose), or start a thread in [Discussions](https://github.com/Tardisyuan/jarvis-showcase/discussions).
- **Point out a mistake** on these pages (a broken link, a wrong number, a claim that doesn't add up): open an issue with the "Something wrong on these pages" form. Pull requests that fix text in this repository are welcome.
- **Take the ideas.** The design notes in [docs/](docs/) are CC BY 4.0: borrow them for your own assistant, with a link back.
- **Get in touch** about a role or a collaboration: the email in the [README](README.md), or the "Work together or hiring" form.
- **Follow along:** watch this repository (Releases) for new notes and big changes.

---

**中文：** 源码不公开（它跑在一个真实的家里），所以不接受代码的 PR，也没有代码可以克隆。可以做的：在 issue 或 Discussions 里提问；指出这些页面上的错误（改这个仓库里文字的 PR 欢迎）；拿走 [docs/](docs/) 里的想法（CC BY 4.0，注明出处）；工作或合作的事发邮件或用「合作或招聘」表单；想看后续就 Watch 这个仓库的 Releases。
