# Security

Jarvis's source code is private, so this repository holds no code to scan or patch. It does describe how Jarvis is kept safe: see the [safety model](docs/safety-model.md) ([中文](docs/safety-model.zh.md)).

If you think a design described here has a hole (for example, a way the model could be talked into a write the rules should stop), please **email the address in the [README](README.md)** rather than opening a public issue. You will get a reply, and if it holds up, the fix and a short write-up, with credit if you want it.

For a broken link or a wrong number on these pages, [open an issue](https://github.com/Tardisyuan/jarvis-showcase/issues/new/choose).
